# ♟️ Wizard's Chess 3D — Gothic Cathedral Edition

An immersive, playable 3D chess game set inside a mysterious Gothic cathedral. Built with Three.js, JavaScript, HTML5, and CSS3, the game combines traditional chess gameplay with atmospheric lighting, detailed 3D pieces, and magical visual effects.

## ✨ Features

- **Immersive 3D Environment:** Gothic cathedral architecture, stone platforms, atmospheric lighting, and mystical visual effects.
- **Complete Chessboard:** A 64-square board with all 32 chess pieces.
- **Marble vs. Obsidian:** Distinctive visual styles for both sides, featuring custom-designed kings, queens, bishops, knights, rooks, and pawns.
- **Interactive Gameplay:** Play chess with two players or challenge the basic Wizard AI mode.
- **Piece Animations:** Floating idle animations, movement animations, and shatter effects when pieces are captured.
- **Game Controls:** New Game, Undo, camera presets, captured-piece tracking, and move history.
- **Responsive Interface:** A minimalist, dark-themed interface designed for desktop and mobile browsers.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js — 3D rendering
- chess.js — Chess rules and move validation

## 🚀 Getting Started

1. Clone this repository:

  bash
   git clone https://github.com/FaizanAhamd/3D-chess-Game.git
  

2. Open the project folder.
3. Open `wizard_s_chess_3d.html` in a modern web browser.
4. Ensure you have an internet connection to load the external JavaScript libraries.

## 🎮 How to Play

- Select one of your chess pieces.
- Choose a highlighted square to make a legal move.
- Capture opponent pieces to see the shatter effects.
- Use the game controls to undo moves, start a new game, or change the camera view.
